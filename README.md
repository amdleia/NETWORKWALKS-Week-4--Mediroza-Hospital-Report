# Week 4 – Web Security Assessment

For Week 4 of my cybersecurity internship with **NetworkWalks**, I worked on a black-box web security assessment. 💻

The main goal was to get more hands-on experience with identifying security weaknesses in a web application and understanding how different findings can connect during an assessment. 🔎

## What I Worked On

During the assessment, I practiced:

* 🔎 Website reconnaissance
* 👤 Username enumeration
* 🔐 Login functionality testing
* 💉 SQL injection testing
* 🚪 Authentication bypass
* 📁 Reviewing accessible files and resources
* 📝 Documenting security findings

## 🔍 My Approach

I started by exploring the website and looking at the pages and resources that were publicly accessible.

I then focused on the login functionality and performed username enumeration to better understand how the application handled different usernames.

After that, I tested the login form for SQL injection as part of the authorized assessment. The testing showed that the login functionality could be bypassed, which allowed access to the patient portal within the project scope.

Once inside the portal, I identified the available files and continued with the next part of the assessment. 📄

## 📚 What I Learned

This project helped me understand why reconnaissance is such an important part of a security assessment.

I also became more comfortable with testing web applications and seeing how different findings can connect to each other and potentially lead to a larger security impact. 💡

Most importantly, it gave me more hands-on practice with web security testing instead of only learning the concepts theoretically. 🧑‍💻

## 🎯 Scope

The testing was performed only against the target provided for the internship project and followed the rules given for the assessment.

* ✅ Testing stayed within the assigned scope
* 🚫 No social engineering was performed
* 🚫 No denial-of-service testing was performed
